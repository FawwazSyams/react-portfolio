# DESIGN.md - Design Direction: Fawwaz Muhammad Syams Portfolio

## 1. Identity & Personality
- **Subject**: Fawwaz Muhammad Syams - Fullstack Web Developer & Graphic Designer from Bandung.
- **Character**: Creative-technologist, authentic, grounded, detail-oriented. A harmonious blend of engineering precision (React, Laravel, Next.js, Python) and visual graphic craft (editorial poster design, branding, typography).
- **Core Narrative**: Building reliable web applications while maintaining high aesthetic standards and real visual storytelling.

## 2. Design Read & Dials
- **Design Read**: Personal portfolio for a creative fullstack developer and graphic designer, in a modern editorial craft style, dial ENERGY 2 / RHYTHM 3 / MOTION 2.
- **ENERGY: 2 (Balanced)** - Professional, confident, clean, human, avoiding over-hyped neon tropes.
- **RHYTHM: 3 (Varied)** - Editorial hero with personal context, asymmetric project layout (flagship feature + supporting cards), dedicated graphic design showcase gallery, interactive tabbed credentials, and a structured contact section.
- **MOTION: 2 (Subtle & Purposeful)** - Smooth micro-interactions, clean hover states, accessible mobile navigation drawer, interactive image preview modal, zero dizzying endless loops or jittery typewriters.

## 3. Palette System (Restrained, High-Contrast, No Generic Purple-Cyan Glows)
- **Canvas Base**: Slate Obsidian (`#0b0f19` / `bg-zinc-950`) - Deep, calm, comfortable contrast without harsh pure black.
- **Surfaces**: Zinc Slate (`#131a29`, `#182234`, `border-zinc-800`) - Solid visual elevation without relying on excessive glassmorphism.
- **Foreground Text**: Crisp Paper White (`text-zinc-100`, `#f8fafc`) and Muted Slate (`text-zinc-400`, `#94a3b8`) strictly meeting WCAG AA 4.5:1+ contrast.
- **Brand Anchor**: Deep Indigo / Cobalt (`#4f46e5`, `#6366f1`) - Used for structural focus and verified credentials.
- **One Deliberate Accent**: Warm Amber (`#f59e0b`, `#fbbf24`) - Used sparingly for live project markers and focal action moments.

## 4. Typography
- **Primary Typeface**: `Plus Jakarta Sans`, sans-serif (clean geometric sans with Indonesian design heritage and exceptional legibility across all weights).
- **Accent / Code**: `JetBrains Mono` / system monospace for technical metadata and stack badges.

## 5. Architectural & Component Decisions (R-31 One-Line Reasons)
- **Layout Rhythm**: Asymmetric composition to give flagship projects room to breathe while presenting supporting apps clearly.
- **No Tilt Glare / Infinite Loops**: Replaced gimmicky parallax tilt and particle clutter with genuine visual hierarchy and crisp content screenshots.
- **Real Graphic Design Gallery**: Dedicated visual showcase with category filters and interactive modal preview to honor his actual poster design work.
- **Fully Accessible Mobile Navigation**: Responsive mobile drawer with keyboard trap and ESC key closing to guarantee mobile UX.
- **Verified Credentials**: Clean list of real certifications with direct verification links and issuer badges.
